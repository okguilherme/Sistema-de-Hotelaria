# 🖧 Trabalho de Sistemas Distribuídos – Comunicação Cliente-Servidor com RMI

Este projeto foi desenvolvido como parte da disciplina de **Sistemas Distribuídos**, ministrada pelo professor **Antonio Rafael Braga**, e tem como objetivo implementar um sistema de comunicação **cliente-servidor** baseado em um **protocolo de requisição-resposta**, conforme descrito na **Seção 5.2** do livro-texto da disciplina.

## 🎯 Objetivo

Desenvolver uma aplicação distribuída utilizando **Java RMI (Remote Method Invocation)** para permitir que um cliente envie requisições a um servidor remoto e receba as respostas apropriadas — **sem o uso direto de sockets**.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Comunicação remota:** Java RMI
